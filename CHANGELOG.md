# Changelog

## 2.0.1
- Licensed under Apache 2.0 (LICENSE, NOTICE, source headers).
- Pregnancy criteria in Decision support are shown only for women.
- PDF report: units such as m² print correctly; the 3D image is cropped square so the report fits on two pages.
- GitHub Pages: root `index.html` redirects to the viewer; README screenshots added.

## 2.0.0
- Decision support: ACC/AHA 2022 and ESC 2024 thresholds by cause, indexed measures.
- Growth compared within the same imaging method (echo or CT/MRI).
- One-click PDF report (English or Spanish).
- Report import from pasted echo or CT text, with preview before applying.
- Spanish interface; plain-language patient view.
- Collision-free text on scan views; analysis organised in tabs.

## 1.2.0
- Parasternal long-axis view, diameter profile chart, 3D camera presets.
- Follow-up with earlier studies and growth criteria.
- Reference sets (Devereux, Lang, WASE), measurement conventions and z-score uncertainty.
- Aortic stiffness inputs; measured strain drives pulsation.

## 1.1.0
- Heartbeat with evidence-based timing, aortic pulsation and illustrative ECG.
- Corrected anatomy (left atrium position), added pulmonary veins, left atrial appendage and arch branches; hover names structures.

## 1.0.0
- Two rotatable 3D models (expected versus entered) and a short-axis scan view that follows the cursor.
